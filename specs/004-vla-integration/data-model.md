# Data Model: VLA Integration Module

## Key Entities

### Voice Command
- **Description**: A spoken natural language instruction that serves as input to the VLA system
- **Attributes**:
  - command_id: string (unique identifier)
  - text_transcription: string (transcribed text from speech)
  - audio_file_path: string (path to original audio file)
  - transcription_confidence: float (confidence score of speech-to-text)
  - timestamp: number (when command was received)
  - speaker_id: string (identifier for the speaker)
  - intent_categories: list of string (potential intents extracted)
  - language: string (detected language of the command)
- **Relationships**:
  - Associated with one Intent Extraction
  - May trigger multiple LLM Action Sequences
- **Validation Rules**:
  - Text transcription must not be empty
  - Confidence score must be between 0 and 1
  - Audio file must exist and be accessible

### Intent Extraction
- **Description**: The process of identifying the goal or purpose from a voice command
- **Attributes**:
  - extraction_id: string (unique identifier)
  - source_command: VoiceCommand (the original command)
  - extracted_intent: string (the primary identified intent)
  - confidence_score: float (confidence in the intent classification)
  - entities_extracted: map of string to string (key-value pairs extracted from command)
  - processing_timestamp: number (when extraction was completed)
  - intent_classifier_version: string (version of the intent classifier used)
- **Relationships**:
  - Belongs to one Voice Command
  - Triggers one or more LLM Action Sequences
- **Validation Rules**:
  - Confidence score must be between 0 and 1
  - Extracted intent must be a valid action type

### LLM Action Sequence
- **Description**: A series of robot actions generated by a Large Language Model from natural language input
- **Attributes**:
  - sequence_id: string (unique identifier)
  - source_intent: string (the intent that generated this sequence)
  - actions: list of ActionStep (sequence of actions to execute)
  - generation_method: string (which LLM model was used)
  - confidence_score: float (confidence in the action sequence validity)
  - estimated_execution_time: number (estimated time in seconds)
  - safety_rating: string (rating of potential safety concerns)
  - ros_action_mapping: map of string to ROSAction (mapping to ROS 2 actions)
- **Relationships**:
  - Generated from one Intent Extraction
  - May include Perception Grounding steps
  - Associated with one VLA Pipeline
- **Validation Rules**:
  - Must contain at least one action
  - All actions must be valid ROS 2 actions
  - Estimated time must be positive

### ActionStep
- **Description**: A single action within an LLM action sequence
- **Attributes**:
  - step_id: string (unique identifier)
  - action_type: string (type of action: navigation, manipulation, sensing, etc.)
  - parameters: map of string to value (action-specific parameters)
  - preconditions: list of string (conditions that must be true before execution)
  - expected_effects: list of string (effects expected after execution)
  - timeout: number (seconds before considering action failed)
- **Relationships**:
  - Belongs to one LLM Action Sequence
- **Validation Rules**:
  - Action type must be valid
  - Parameters must match the action type requirements

### Perception Grounding
- **Description**: The process of connecting language-based commands to specific visual entities in the environment
- **Attributes**:
  - grounding_id: string (unique identifier)
  - source_command: string (the original command requiring grounding)
  - target_entities: list of DetectedObject (objects to act upon)
  - spatial_relationships: list of string (relationships like "left of", "next to")
  - confidence_score: float (confidence in the grounding)
  - detection_timestamp: number (when objects were detected)
  - bounding_boxes: list of BoundingBox (visual bounding boxes of detected objects)
- **Relationships**:
  - Associated with one LLM Action Sequence
  - Contains multiple DetectedObjects
- **Validation Rules**:
  - Confidence score must be between 0 and 1
  - Must have at least one target entity for grounding-dependent actions

### DetectedObject
- **Description**: An object detected in the environment by perception systems
- **Attributes**:
  - object_id: string (unique identifier)
  - object_class: string (type of object: "red ball", "blue mug", etc.)
  - confidence_score: float (confidence in detection)
  - bounding_box: BoundingBox (location in image space)
  - world_coordinates: Vector3 (location in 3D world space)
  - color: string (dominant color if relevant)
  - size_category: string (small, medium, large)
  - detection_timestamp: number (when object was detected)
- **Relationships**:
  - Belongs to one Perception Grounding
  - May be referenced by multiple ActionSteps
- **Validation Rules**:
  - Confidence score must be between 0 and 1
  - Bounding box coordinates must be valid

### BoundingBox
- **Description**: A rectangular region in image space that bounds a detected object
- **Attributes**:
  - x: number (top-left x coordinate)
  - y: number (top-left y coordinate)
  - width: number (width of the box)
  - height: number (height of the box)
  - center_x: number (center x coordinate)
  - center_y: number (center y coordinate)
- **Relationships**:
  - Belongs to one DetectedObject
- **Validation Rules**:
  - Coordinates must be non-negative
  - Width and height must be positive

### Vector3
- **Description**: A 3D vector representing a position in world space
- **Attributes**:
  - x: number (x coordinate)
  - y: number (y coordinate)
  - z: number (z coordinate)
- **Relationships**:
  - Used by DetectedObject for world coordinates
- **Validation Rules**:
  - Coordinates must be finite numbers

### VLA Pipeline
- **Description**: An integrated system that connects voice input, language understanding, planning, perception, and action execution
- **Attributes**:
  - pipeline_id: string (unique identifier)
  - name: string (name of the pipeline configuration)
  - voice_components: list of string (components in the voice processing chain)
  - llm_components: list of string (components in the LLM processing chain)
  - perception_components: list of string (components in the perception chain)
  - action_components: list of string (components in the action execution chain)
  - processing_latency: number (average time for full pipeline execution)
  - success_rate: float (overall success rate of the pipeline)
  - configuration: map of string to value (configuration parameters)
- **Relationships**:
  - Contains many Voice Commands (processed through the pipeline)
  - Contains many LLM Action Sequences
  - Contains many Perception Groundings
- **Validation Rules**:
  - Success rate must be between 0 and 1
  - Latency must be positive

## State Transitions

### Voice Command State Transitions
- RECEIVED → TRANSCRIBING (when speech-to-text starts)
- TRANSCRIBING → TRANSCRIBED (when transcription completes)
- TRANSCRIBED → INTENT_EXTRACTING (when intent extraction starts)
- INTENT_EXTRACTING → INTENT_EXTRACTED (when intent extraction completes)
- INTENT_EXTRACTED → PLANNING (when LLM planning starts)
- PLANNING → PLANNED (when action sequence is generated)
- PLANNED → EXECUTING (when robot starts executing actions)
- EXECUTING → COMPLETED/SUCCESS (when all actions complete successfully)
- EXECUTING → FAILED (when execution fails)

### LLM Action Sequence State Transitions
- GENERATED → VALIDATING (when safety checks run)
- VALIDATING → VALIDATED (when safety checks pass)
- VALIDATED → QUEUED (when placed in execution queue)
- QUEUED → EXECUTING (when execution starts)
- EXECUTING → COMPLETED (when all steps complete)
- EXECUTING → FAILED (when execution encounters error)
- FAILED → RECOVERY (when recovery procedures activate)

## Entity Relationships

```
[VoiceCommand] 1---1 [IntentExtraction]
[IntentExtraction] 1---* [LLMActionSequence]
[LLMActionSequence] *---* [ActionStep]
[LLMActionSequence] 1---* [PerceptionGrounding]
[PerceptionGrounding] 1---* [DetectedObject]
[DetectedObject] 1---1 [BoundingBox]
[DetectedObject] 1---1 [Vector3]
[VLAPipeline] 1---* [VoiceCommand]
[VLAPipeline] 1---* [LLMActionSequence]
[VLAPipeline] 1---* [PerceptionGrounding]
```

## Validation Rules

### Voice Command Validation
- Audio file must be in a supported format (WAV, MP3, etc.)
- Transcription confidence must meet minimum threshold for processing
- Command must be within acceptable length limits
- Language must be supported by the system

### Intent Extraction Validation
- Extracted intent must map to a valid action type in the system
- Confidence score must exceed minimum threshold for action execution
- Entities extracted must be consistent with the detected intent
- Intent classifier version must be current and supported

### LLM Action Sequence Validation
- All actions in the sequence must be executable by the target robot
- Action preconditions must be satisfied before execution
- Safety rating must be within acceptable limits
- Estimated execution time must be reasonable for the task

### Perception Grounding Validation
- Detected objects must be within the robot's operational range
- Spatial relationships must be physically possible
- Confidence scores must meet minimum thresholds for action execution
- Target entities must be reachable by the robot's manipulators (if applicable)
