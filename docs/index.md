# Physical AI & Humanoid Robotics Education

Welcome to the comprehensive educational platform for Physical AI & Humanoid Robotics! This curriculum covers the integration of robotics, artificial intelligence, and human-robot interaction through four comprehensive modules.

## Overview

This educational platform provides hands-on learning experiences in:
- **ROS 2 Nervous System**: Robot Operating System 2 as the communication backbone
- **Digital Twin (Gazebo & Unity)**: Simulation environments for testing and development
- **Isaac AI Brain**: NVIDIA Isaac for AI-powered robotics
- **Vision-Language-Action (VLA) Integration**: Natural human-robot interaction systems

## Getting Started

Begin your journey by exploring the modules in sequence:

1. [Module 1: ROS 2 Nervous System](./modules/01-ros2-nervous-system/index.md) - Start with the fundamentals of robot communication
2. [Module 2: Digital Twin](./modules/02-gazebo-unity-digital-twin/index.md) - Learn simulation and digital twin technologies
3. [Module 3: Isaac AI Brain](./modules/03-isaac-ai-brain/index.md) - Explore AI-powered robotics with NVIDIA Isaac
4. [Module 4: VLA Integration](./modules/04-vla-integration/index.md) - Master vision-language-action systems

## Learning Path

Each module builds upon the previous ones, providing a comprehensive understanding of modern robotics systems. The curriculum combines theoretical knowledge with practical implementation, preparing you for real-world robotics development.

## Prerequisites

- Basic programming knowledge (Python recommended)
- Understanding of robotics concepts
- Familiarity with Linux command line
