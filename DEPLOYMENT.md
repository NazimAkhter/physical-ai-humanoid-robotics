# Deployment Guide for Physical AI & Humanoid Robotics Platform

## GitHub Pages Deployment

The Physical AI & Humanoid Robotics educational platform is deployed to GitHub Pages using GitHub Actions. Here's how the deployment process works:

### Automatic Deployment (Recommended)

The site is automatically deployed when changes are pushed to the main branch using GitHub Actions:

1. Push your changes to the `main` or `004-vla-integration` branch
2. GitHub Actions will automatically trigger the deployment workflow
3. The workflow will:
   - Checkout the repository
   - Install dependencies
   - Build the Docusaurus site
   - Deploy the built site to the `gh-pages` branch

### Manual Deployment

If you need to deploy manually, you can run:

```bash
# Build the site
npm run build

# Deploy using Docusaurus command (requires proper environment variables)
GIT_USER=<your-username> USE_SSH=false npm run deploy
```

### GitHub Actions Workflow

The deployment is handled by the workflow in `.github/workflows/github-pages.yml`. This workflow:
- Runs on pushes to main and 004-vla-integration branches
- Sets up Node.js environment
- Installs dependencies with `npm ci`
- Builds the site with `npm run build`
- Deploys the built site to the `gh-pages` branch

### Site Configuration

The site is configured for GitHub Pages deployment in `docusaurus.config.js`:
- `baseUrl` is set to `/physical_ai_book/` to match the repository name
- `organizationName` is set to `NazimAkhter`
- `projectName` is set to `physical_ai_book`
- The site is configured to be deployed to `https://nazimakhter.github.io/physical_ai_book/`

### Troubleshooting

If the deployment fails:
1. Check the GitHub Actions logs for error details
2. Verify that the `gh-pages` branch exists in the repository
3. Ensure that the build process completes successfully locally before pushing
4. Verify that all links are valid and not causing broken link errors

### Branch Structure

- `main` or `004-vla-integration`: Source code and documentation
- `gh-pages`: Built site files (automatically generated by GitHub Actions)
